# Technical SEO Checklist

A practical checklist for performing a Technical SEO audit and identifying issues that can affect organic search performance.

## What This Checklist Covers

### Crawling & Indexing
- Robots.txt
- XML Sitemap
- Noindex directives
- Canonical tags
- Crawlability
- Index coverage
- Duplicate URLs

### Website Architecture
- URL structure
- Internal linking
- Breadcrumbs
- Site hierarchy
- Orphan pages

### Technical Performance
- Page speed
- Core Web Vitals
- Mobile usability
- HTTPS
- Server response time

### On-Page Technical Elements
- Title tags
- Meta descriptions
- Heading structure
- Image optimization
- Structured data

### Redirects & Status Codes
- 301 redirects
- 302 redirects
- 404 errors
- Redirect chains
- Broken links
